课件特性

Features
🎙️

课文全文范读

逐段真人级语音朗读，可反复播放，学生跟着读。

🗣️

每页旁白讲解

老师口吻的知识点导学，翻到哪页讲哪页。

🔊

点击"钥匙 / 五彩缤纷 / 喇叭"，点了就发音。

🎵

翻页声、答对答错提示音、雨声环境音，均可开关。

🖐️

互动练习

连一连 + 单选题，作答即时反馈并自动记录。

📶

完全离线

单个 HTML 文件，音频内嵌，拷贝到 U 盘就能上课。

怎么用

How to use

打开课件

点「打开《秋天的雨》课件」，进入后点击中间的

「🔊 点击开始上课」解锁声音。

开始上课

翻页会自动播报本页旁白；需要学生跟读时，点页面上的「朗读本段」按钮。

自由跳转

底部可「首页 / 尾页 / 任意页跳转」，键盘 ← → 空格 Home End 也能翻页。

离线使用

把课件的 HTML 文件下载下来，双击即可；教室电脑没网也能上。

💡 小提示：浏览器规定"必须先有一次点击才允许播放声音"，所以进入课件后请先点一下「开始上课」，之后所有声音就都正常了。投屏时可按右下角「⛶ 全屏」。
